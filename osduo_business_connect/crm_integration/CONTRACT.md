# CRM Integration Contract

**Version:** 1.0
**Date:** 2026-09-01
**Status:** Phase 1 Definition

---

## Overview

This document defines the contract between OSDuo Business Connect and Frappe CRM for lead generation and ownership.

---

## Ownership Model

### Key Principle

Every CRM Lead generated by OSDuo carries an explicit `osduo_business` Link to the OSDuo Business that owns the acquisition channel.

**Business does NOT have a `crm_organization` Link field.**

### Why?

In Frappe CRM, `Lead.organization` represents the **prospect's organization** (the company the lead works for). It does NOT represent the OSDuo customer's own business.

```
OSDuo Business: ABC Engineering
   │
   └── receives enquiry from John at XYZ Industries
              │
              ▼
       CRM Lead: John
          ├── organization = XYZ Industries (prospect's company)
          └── osduo_business = ABC Engineering (which business owns this lead)
```

**NOT:**
```
CRM Lead: John
   └── organization = ABC Engineering (WRONG — this is the OSDuo customer, not the prospect)
```

## Custom Fields on CRM Lead

The following custom fields will be added to the CRM Lead DocType via Frappe's Custom Field mechanism:

| Field Name | Field Type | Options | Description |
|------------|------------|---------|-------------|
| `osduo_business` | Link | Business | Which OSDuo Business owns this lead |
| `osduo_card` | Link | Digital Card | Which card generated this lead |
| `osduo_product` | Link | Showcase Product | Which product generated this lead |
| `osduo_service` | Link | Showcase Service | Which service generated this lead |
| `osduo_enquiry` | Link | Business Enquiry | The originating enquiry |
| `osduo_campaign` | Data | — | Campaign attribution |

### Native CRM Fields (Retained)

| Field | Meaning |
|-------|---------|
| `organization` | Prospect's company (NOT the OSDuo customer) |
| `lead_name` | Visitor name |
| `email_id` | Visitor email |
| `mobile_no` | Visitor phone |
| `lead_source` | Source attribution |

## Multi-Business Isolation

On a shared Frappe site with multiple OSDuo Businesses, CRM records must be isolated:

```
Business A user → sees only Leads where osduo_business = Business A
Business B user → sees only Leads where osduo_business = Business B
```

### Implementation

```python
# permission_query_conditions hook on CRM Lead
def get_lead_permission_query_conditions(user):
    """Filter CRM Leads by OSDuo Business membership."""
    from osduo_business_connect.business.business.business import get_user_businesses

    businesses = get_user_businesses(user)
    if not businesses:
        return "1=0"

    business_names = [b["name"] for b in businesses]
    return f"`tabCRM Lead`.osduo_business IN ({', '.join(['%s'] * len(business_names))})"
```

### Hooks Configuration

```python
# In hooks.py
permission_query_conditions = {
    "CRM Lead": "osduo_business_connect.crm_integration.lead_mapper.get_lead_permission_query_conditions",
}
```

## Lead Creation Flow

### Business Enquiry → CRM Lead

```
Visitor
   ↓
OSDuo Public Profile (Business Enquiry form)
   ↓
Business Enquiry (status=New)
   ↓
Background Job (with retry)
   ↓
CRMLeadService.create_from_enquiry()
   ↓
CRM Lead
   ├── osduo_business = Business
   ├── osduo_card = Digital Card (if applicable)
   ├── osduo_product = Showcase Product (if applicable)
   ├── osduo_service = Showcase Service (if applicable)
   ├── osduo_enquiry = Business Enquiry
   └── osduo_campaign = Campaign attribution
```

### Status Flow

```
Business Enquiry (mirrors CRM Lead status 1:1):
   New → Contacted → Nurture → Qualified → Converted
                     → Unqualified / Junk (lost)
                     → Closed / Spam (enquiry-only)

CRM Lead (drives enquiry status):
   New → Contacted → Nurture → Qualified → Converted
                     → Unqualified / Junk (lost)
```

## Implementation Notes

1. **Custom fields are added via Frappe's Custom Field mechanism**, not by modifying CRM's DocType JSON directly.

2. **Permission query conditions** are registered in hooks.py and filter CRM Leads by `osduo_business`.

3. **Background job with retry** ensures enquiry data is never lost due to CRM unavailability.

4. **No ERPNext integration** in v1/v2. When ERPNext is installed, Frappe CRM's native integration handles Deal → Customer → Quotation.

## Future Considerations

- If a concrete CRM use case requires explicit Business→Organization mapping, it can be added as a separate field (e.g., `crm_profile`) without disrupting existing data.
- Multi-owner support may be added in v2 if needed.
- CRM Deal ownership may follow a similar pattern if needed.
